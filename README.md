# Handwritten English Alphabet Recognition using CNN

A CNN-based image classification project that reads a 28×28 grayscale image of a single
handwritten English capital letter and predicts which of the 26 letters (A–Z) it is.

The motivation is everyday handwriting that is hard to read — a classic example is a doctor's
prescription, which patients and sometimes even pharmacists struggle to read. Recognising one
letter at a time is the basic building block of larger optical character recognition (OCR)
systems, and this project focuses on that building block.

This repository contains the Phase 2 proposal and the full code implementation.

## Dataset

- **Name:** A–Z Handwritten Alphabets (CSV format)
- **Link:** https://www.kaggle.com/datasets/sachinpatel21/az-handwritten-alphabets-in-csv-format
- **Images:** 372,451 (one per CSV row)
- **Classes:** 26 (capital letters A–Z)
- **Image type:** 28×28 grayscale, single channel
- **Format:** one CSV file, 785 columns, no header. Column 1 is the label (0 = A … 25 = Z);
  the remaining 784 columns are the flattened 28×28 pixels (0–255).
- **Class balance:** heavily imbalanced — the most common letter (O) has 57,825 images, while the
  least common (I) has only 1,120. This is handled with stratified splitting, data augmentation,
  and class weights.

> The dataset itself is **not** included in this repository because of its size. Download it from
> the Kaggle link above, or add it directly to a Kaggle notebook.

## How to run

The project is built to run on a **Kaggle Notebook** (TensorFlow / Keras come pre-installed).

1. Create a new notebook on Kaggle and upload `AZ_Handwritten_CNN.ipynb` (File → Import Notebook).
2. Click **Add Input** and search for *A-Z Handwritten Alphabets in CSV format*; add it.
   The notebook finds the CSV automatically under `/kaggle/input`.
3. Turn on the **GPU** accelerator (Settings → Accelerator → GPU).
4. Run all cells (Run → Run All).

On the full 372,451 images, a complete run takes roughly **30–45 minutes** on a Kaggle GPU.
For a quick test, set `SAMPLE_FRACTION = 0.2` in the configuration cell to run on part of the data.

Other useful flags in the config cell:

- `USE_CLASS_WEIGHTS` — weight rare letters more during training (on by default)
- `DO_FINETUNE` — run the optional MobileNetV2 fine-tuning stage (on by default)
- `EPOCHS`, `BATCH`, `SEED` — standard training settings

### Running outside Kaggle

It also runs in any Python environment with the libraries below. Edit the dataset path in the

## What the code does

The notebook follows the proposed methodology step by step:

1. Load the CSV and split into pixel features and labels
2. Reshape each row into a 28×28×1 image and normalise pixels to 0–1
3. Stratified train / validation / test split (70 / 15 / 15)
4. Data augmentation (small rotations, shifts, zoom) on the training set
5. Custom CNN (three Conv + MaxPool blocks → Flatten → Dropout → Dense → 26-way softmax)
6. Transfer learning with MobileNetV2 (images resized to 32×32 and copied to 3 channels)
7. Evaluation on the held-out test set
8. Confusion matrix, classification report, accuracy/loss curves, per-class recall, ROC curves,
   model comparison, Grad-CAM, and error analysis
9. Saving the trained models, figures (PDF), and tables (CSV)

## Models

- **Custom CNN** — trained from scratch on the native 28×28 grayscale images.
- **MobileNetV2 (transfer learning)** — pre-trained on ImageNet, used as a feature extractor with
  a new classification head, then optionally fine-tuned.
